# 6-depth 분석 대시보드 스펙 정합화 — 설계

2026-09-06 · 승인: 사용자 (목업 3화면 + 4개 결정 확정)

## 목적

대시보드를 "숫자를 보여주는 현황판"이 아니라 **변화 발견 → 원인 추적 → 확인 지점 안내** 도구로 만든다.
모든 화면은 `현재 값 → 전월 동기간 대비 변화 → 변화 원인 → 상세 원인` 3단 구조를 유지하고,
모든 인사이트는 클릭으로 다음 depth로 이어진다.

IA: 홈 → 카테고리(/categories, /categories/[그룹]) → 카테고리×렌탈사(/categories/[그룹]/[렌탈사]) → **상품(신규)**
　　홈 → 전체 렌탈사(/companies) → 렌탈사 상세(/company/[렌탈사]) → 카테고리×렌탈사 → 상품
BM은 페이지가 아니라 분석 축/필터.

> **구현 중 변경(2026-09-06, 사용자 추가 스펙 — 병행 세션에 전달됨)**: 카테고리 라우트 파라미터가
> 3축(가전&상조/정수기/인터넷)에서 **6그룹 키**(정수기/공청기·비데/대형가전/타이어/기타/인터넷)로
> 전환됐다. "정수기"·"인터넷"은 축 이름이자 그룹 이름이므로 분기 시 그룹 판정을 먼저 한다.
> /companies는 카드 그리드가 아니라 **테이블 기본 + [전체|T1|T2|기타] 티어 탭 + 상위 성과·이상만
> 카드 강조**로 확정. 카테고리 축 페이지들(app/categories/**, Sidebar/Header, lib/biz-category)은
> 병행 세션이, 홈·렌탈사 축·공용 lib는 이 세션이 담당했다.

## 확정 결정 (2026-09-06)

1. **상품 최종 depth = 개별 상품(product_name) 단위** — `/categories/[축]/[렌탈사]/[상품명URL인코딩]`.
   "얼음정수기" 같은 상품군 클러스터는 만들지 않는다(컬럼 없음, 키워드 규칙 애매).
2. **렌탈사 상세는 스펙 구조로 재구성** — 레거시 섹션은 삭제하지 않고 접힌 `<details>` "상세 데이터"로 보존.
3. **홈은 스펙대로 개편** — 리드 문장에 핵심 수치 병기, 성과 기여 [카테고리|렌탈사|BM] 탭 통합,
   세부 카테고리 카드 그리드는 홈에서 제거(→ /categories 인덱스가 담당).
4. **상태는 3단계 통일** — 🔴 이상(sev-crit) / 🟣 확인 필요(primary 인디고 — DESIGN.md에 보라 없음) / 🟢 정상(회색).
   기존 crit→이상, warn·info→확인 필요, ok·hot→정상. 판정 사유는 텍스트로 보존. 색+라벨 항상 병기.

## 구현 범위

### 공통 기반
- `lib/status.ts` — 3단계 판정 단일 소스(`judgeState`), 기존 `cardKit.judgePace`(4단계)와 홈 `SEV_STYLE` 수렴.
- `lib/format.ts` — `pct`/`pctAbs`/`manwon`/`recentYms` 승격 (현재 4벌 복제).
- `app/components/Delta.tsx` — 증감 표기 공용 컴포넌트 (4벌 복제 해소).
- `app/components/Breadcrumb.tsx` — `홈 › {축} › {렌탈사} › {상품}` 공용.
- `lib/decompose.ts` 확장 — `marginDecompose`: Δ공헌이익 = 판매량 효과 + 건당(within) + 믹스.
- 홈의 로컬 카테고리 정의(KNOWN_CATS/LARGE_CATEGORY_GROUPS/LARGE_TO_BIZ)를 `lib/biz-category.ts`로 수렴.

### 상품 페이지 (신규 라우트 — 유일한 신규 페이지)
`app/categories/[category]/[company]/[product]/page.tsx`
① KPI 4종(조합 한정, 전월 동기간 대비) ② 12개월 추이(지표 선택) ③ 매출 분해(판매량×단가)
④ 가격(`monthly_fee`) ⑤ 수수료(`sales`/건, `sales_incentive`) ⑥ 프로모션(`promotion` — 비면 섹션 숨김)
⑦ 믹스(`management_type`, `contract_months`) ⑧ 수익성(건당 공헌이익 + `cost_of_goods`/`financial_cost`/`bad_debt`).

### 카테고리 × 렌탈사
- Breadcrumb 추가. 상품별 성과 표 행 + 증가/감소 기여 상품 → 상품 페이지 링크(현재 링크 없음).
- "지표별 변화 원인" 요약 패널: 거래액/매출 = 건수×단가 분해, 건당 공헌이익 = within/mix.

### 렌탈사 상세 (`/company/[렌탈사]`)
본문 재구성: ① KPI 4종 ② 기간별 추이(지표 4종) ③ 카테고리별 성과(6그룹, 행→조합 페이지)
④ 상품별 성과(행→상품 페이지) ⑤ 증감 요인(증가/감소 기여) ⑥ 수익성 분해(판매량+건당+믹스).
기존 본문(뷰 토글·월별 매트릭스·포지션 차트·BM 필터 뷰)은 접힌 "상세 데이터"로 이동.

### 홈 (`app/page.tsx`)
- 제목 "{N}월 한눈에 보기" 동적화. 리드 문장에 수치 병기(topUp/topDown 로직 재사용).
- 주의 신호/확인 필요 → 3단계 상태 매핑(행 구조·클릭 이동은 현행 유지).
- 성과 기여 [카테고리|렌탈사|BM] 탭: 카테고리=6그룹 순증 기여+"카테고리 전체 보기→/categories",
  렌탈사=Top5+"전체 렌탈사 보기→/companies", BM=현행 패널(믹스바+within/mix) 이동.
- 세부 카테고리 카드 그리드 제거. 접힌 상세 데이터는 유지.

### 전체 렌탈사 / 카테고리 인덱스 / 내비
- `/companies`: BM 필터·티어 필터 추가(티어 요약 칩→클릭 필터), 카드 상태 3단계.
- `/categories`(untracked 신규) 정식화: 사이드바 진입 링크, Header 제목·기준 배지 케이스 추가.
- 카드류(CategoryCards/CompanyCards) 상태 3단계 통일.
